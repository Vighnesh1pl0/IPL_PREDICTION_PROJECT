# IPL Win Predictor 🏏

##  Project Overview
The **IPL Win Predictor** is a machine learning application that predicts the winning probability of IPL teams during a live match. It uses historical IPL match data and real-time match inputs to estimate the chances of each team winning.

The project demonstrates the practical application of machine learning in sports analytics and is deployed as an interactive web application.

---

##  Features
- Predicts win probability for both teams
- Takes real-time match inputs (runs, overs, wickets, target)
- User-friendly interface
- Machine learning–based prediction model

---

## Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Streamlit (for web app)
